# C-Lab

A personal **C programming lab** to explore and consolidate knowledge in:

- **Data Structures & Algorithms** (DSA)
- **Graph Theory**
- **Algorithm Design & Analysis**
- **Mini Projects**: games,...

This repository serves as a **learning playground** and long-term reference for all things C.

## 📝 Usage

1. Clone the repository:

```bash
git clone https://github.com/namnguyen2k1/c-lab.git
cd c-lab
```

2. Navigate to any folder and compile the C programs:

```bash
gcc filename.c -o output
./output
```

3. Add your own experiments, mini projects, or algorithm implementations.
